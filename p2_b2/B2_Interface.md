# B2 certified-bound reference interface

This interface is saved before implementation, using the saved mathematical checkpoint. Code will use the read-only A2 exact `Matrix` type, with `Fraction` entries and n output rows by d input columns. Numerical bound results are dictionaries containing exact Fractions, immutable word tuples and exact matrices; `record(value)` converts them recursively to JSON-compatible numerator/denominator pairs and explicit matrix shapes. Bounds never authorize a live commit.

## Exact norm and geometry helpers in `certified_bounds.py`

- `sqrt_bounds(q, bits=80) -> (lower, upper)`: q is a nonnegative rational. Perfect rational squares return equal endpoints; otherwise exact powers of two normalize q into [1,4), integer-square-root arithmetic encloses the normalized root with dyadic width 2^-bits, and both endpoints are rescaled exactly. Thus bits specifies normalized fractional precision, not an absolute error floor that would hide tiny/subnormal responses. No floating SVD or host square root is used.
- `norm2_bounds(values, bits=80) -> (lower, upper)` for a finite rational vector.
- `spectral_upper(A, bits=80) -> Fraction`: square-root upper bound on `min(||A||_F^2, ||A||_1 ||A||_infinity)`.
- `geometry_bound(delta, H, h, U=None, basis_route="projector", bits=80) -> dict`. H generates the declared reference space V. The point residual is exactly `e=(I-Pi_V)h`, and x=`Pi_V h`. `projector` uses exact `Pi_V` and the bound `||delta Pi_V|| ||x|| + ||delta|| ||e||`. `orthonormal` requires `U.T U=I` and equal exact projectors, then uses `||delta U|| ||x|| + ||delta|| ||e||`; ||x|| equals the orthonormal coefficient norm. `approximate` separately certifies the Gram error delta_G, requires delta_G<1, constructs the exact projector onto col(U), certifies sigma=`||Pi_V-Pi_U||`, and uses `((||delta U||/sqrt(1-delta_G))+||delta|| sigma)||x|| + ||delta|| ||e||`. The reciprocal is obtained by an outward-certified square-root upper bound of `1/(1-delta_G)`; unresolved conditioning is refused, not silently treated as orthonormal. If V is already proved to contain the actual legal input, e is zero. Nonzero e requires a declared reference/perturbed-envelope interpretation.
- Geometry output keys: `bound`, `uniform_bound`, `actual_change`, `actual_norm_lower`, `actual_norm_upper`, `h_norm_upper`, `protected_component_norm_upper`, `residual`, `residual_norm_upper`, `delta_norm_upper`, `protected_action_norm_upper`, `basis_route`, and route-specific `gram_error_upper`, `projector_deviation_upper`, `inverse_condition_upper`. The displayed core `bound` is not silently replaced by the optional uniform bound.
- `error_ledger(chain, h=None, bits=80) -> dict`: chain is a nonempty sequence of unique `(name, exact_matrix)` pairs. The first matrix is the explicitly declared ideal/base increment; every next stage differs by a distinct exact telescoping term. Output includes the exact net increment, signed stage errors, baseline and term bounds, `bound`, and `accounting="telescoping_alternative_to_direct_endpoint"`. With h, terms are applied to that point before norm bounds; without h, spectral upper bounds are used. The identity proves accounting, not that a supplied ideal optimizer or host computation was itself certified.

## Affine execution and point bounds

- `decode_matrix(words, fmt) -> Matrix` and `decode_vector(words, fmt) -> tuple[Fraction,...]` validate canonical finite BF16/FP32 words.
- `trace_affine(weights, h, fmt, bias=None) -> dict` uses fixed bias-first ascending-column separate multiply/add execution and the existing P1 actual word operations. The bias defaults to n canonical zeros. Both inputs and outputs must be finite and canonical. It records each product/add exact argument, rounded word, signed local error and absolute error; the local signed errors telescope exactly to the observed output minus the exact affine value.
- Trace keys: `output_words`, `decoded_output`, `exact_output`, `row_signed_errors`, `row_error_bounds`, `rho_l2`, `rho_linf`, `rows`, `arithmetic_counts`, `totality="actual_trace_checked"`. Each row has its ordered `events`. Any actual overflow or unsupported word refuses. Optional mixed-error annotations are separated from the unconditional exact local residuals.
- `point_bound(old_words, new_words, h_words, fmt, old_bias=None, new_bias=None, bits=80) -> dict`: both old/new traces are executed independently. `new_bias=None` means reuse the old bias; omitted old bias is zero. The exact algebraic change is decoded `(W'-W)h+(b'-b)`. Output keys include `old_trace`, `new_trace`, `effective_delta`, `bias_delta`, `exact_change`, `exact_change_norm_upper`, `actual_change`, `actual_norm_lower`, `actual_norm_upper`, `coordinate_bounds`, `linf_bound`, `l2_bound`, `reference_output_norm_lower`, `relative_bound` and `scope="one_declared_input_only"`.
- Coordinate bound i is `abs(exact_change_i)+rho_old_i+rho_new_i`; the two-norm bound is `norm2(exact_change)_upper+rho_old_l2+rho_new_l2`. A certified reference lower bound is `max(abs(decoded_old_output_i))`. Relative bound is undefined (`None`) when that lower bound is zero.
- `mixed_budget(bound, reference_lower, absolute_budget, relative_budget) -> dict` accepts exactly when the nonnegative certified bound is at most `absolute_budget + relative_budget*reference_lower`. This is a sufficient mixed-budget condition even at zero; it is not a division by a zero reference.

## Analytic complete-box bound

- `box_bound(old_words, new_words, coordinate_bounds, fmt, old_bias=None, new_bias=None, bits=80) -> dict` applies to every admitted raw h with `abs(decode(h_j)) <= coordinate_bounds[j]`. The coordinates are nonnegative exact rationals. Domain provenance/inclusion belongs to the calling bounded-certificate registry, not to this helper.
- Let M be the largest finite value, u=2^-p and eta the minimum positive subnormal. For each endpoint/row, start with accumulator bound `a=abs(bias)`. At each column, check `x=abs(weight)*H_j <= M`, use product error `u*x+eta/2` and product bound `p=min(M,x+u*x+eta/2)`. Check `z=a+p <= M`, use addition error `u*z+eta/2`, and continue with `a=min(M,z+u*z+eta/2)`. Sum the separate local errors. A failed range check is a conservative inability to certify totality, not necessarily an actual overflowing input.
- The algebraic coordinate change bound is `abs(bias_delta_i)+sum_j abs(effective_delta_ij)*H_j`. Add the two endpoint row-error bounds for `coordinate_bounds`/`linf_bound`; separately combine their Euclidean bounds for `l2_bound`. Output also records endpoint range recurrences, input bounds, exact field constants, `totality="proved_for_stated_box"`, and `scope="all_admitted_raw_inputs_in_stated_box"`.

The point and box APIs support general fixed finite bias values and explicit changed biases. They certify full output vectors, not an unspecified downstream observation. They preserve canonical-zero, gradual-underflow and fixed non-FMA semantics. Direct effective-delta bounds already include upstream generation/storage effects; one must not add an upstream ledger to that same direct bound a second time.
