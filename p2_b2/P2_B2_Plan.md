## Chosen scope and nonclaims

The protected arithmetic is finite canonical BF16/FP32 with RNE, gradual underflow, fixed ordered separate multiply/add and explicit zero canonicalization. Stored inputs/weights/biases reject NaN, infinity and negative zero. Bias is fixed in registered examples; a general affine diagnostic may add an explicitly identified bias difference without changing the implemented bias-first graph. Host AdamW proposals remain separately specified computations; direct endpoint bounds include their effects without pretending an ideal host square root/power has been certified.

A point bound covers that input only. A complete registered-domain maximum covers exactly that declared domain. An analytic envelope bound is universal over its stated domain only when inclusion and arithmetic totality are certified. Neither sampled low rank nor a numeric basis label supplies global provenance. A strictly sub-lattice-step output bound can imply BIT only under a separate canonical finite-output separation proof and full domain coverage; program lifting still needs A3's fixed-D/input/schedule/invariant premises.

No GPU/native-BF16/general-concurrency/arbitrary-compiler certification, universal learning performance, complete machine proof or later-stage composition guarantee is inherited. Cost and tightness are measured for the actual small checks, not offered as a performance advantage.
