# P2-B2 mathematical checkpoint

Saved after reading the B2 plan and before B2 implementation. The full proofs will refine these statements; no finite test is used as a universal premise.

1. **Actual endpoint geometry.** Let Delta=W'-W be the exact decoded difference of accepted finite stored matrices. Let Q have orthonormal columns spanning the true protected real subspace V, and write h=Qa+e with Q^T e=0. With epsilon >= ||Delta Q||_2 and M >= ||Delta||_2, the exact output difference satisfies ||Delta h||_2 <= epsilon ||a||_2 + M ||e||_2. The zero/full-rank cases and zero inputs use their natural empty-coordinate interpretations. Each term is separately sharp; both terms need not be simultaneously attainable for prescribed norms because ||Delta||_2 couples the blocks. A universal sharper alternative is the minimum with M||h||_2. No orthogonality claim alone supplies finite execution equality.

2. **Approximate basis.** A decoded full-column matrix U is not treated as orthonormal. If delta >= ||U^T U-I||_2 and delta<1, its exact projector is Pi_U=U(U^TU)^(-1)U^T. Let alpha >= 1/sqrt(1-delta), epsilon_U >= ||Delta U||_2, and sigma >= ||Pi_U-Pi_V||_2 for a separately justified true projector Pi_V. Then ||Delta v||_2 <= (epsilon_U alpha+M sigma)||v||_2 for v in V. Rational interval/algebraic upper bounds can certify these inequalities; sampled activations or a fitted basis cannot establish Pi_V provenance.

3. **Disjoint candidate ledger.** For an ideal candidate G_* and exact intended complementary projector P, let C_*=G_*P, a represented projector P_tilde, computed optimizer candidate G_hat and generated ideal-before-storage increment D_hat. Define E_repr=G_*(P_tilde-P), E_opt=(G_hat-G_*)P_tilde, E_gen=D_hat-G_hat P_tilde, E_store=Delta-D_hat. Then Delta=C_*+E_repr+E_opt+E_gen+E_store exactly. A direct bound on actual Delta already includes all these effects and must not add the ledger again. A factorized generator uses its own combined representation term instead of an overlapping projector term.

4. **Two rounded executions.** For a fixed bias-first ordered separate multiply/add graph with finite RNE outputs, gradual underflow and canonical zeros, the local inequality |RN(x)-x| <= u|x|+eta/2 uses u=2^(-p), smallest positive subnormal eta and an explicitly certified finite/total operation range. Exact local residuals telescope into the row error. Thus |yhat'-yhat| <= |Delta h+delta_b| + beta_old+beta_new coordinatewise, and induced vector bounds follow. Bounds on Delta h alone omit two independent rounding errors. Overflow or a changed graph invalidates this contract.

5. **Global envelope and BIT boundary.** Analytic box envelopes require proven coverage of every relevant shared call and induction over operation ranges. Point traces cover one input; finite maxima cover only their complete declared domain. Relative claims require a positive lower bound on the chosen reference output norm. A mixed absolute/relative bound is meaningful at zero. Since canonical finite values differ by at least eta, a strict full-domain infinity-norm difference bound <eta implies BIT for those full output words; <=eta does not. Program-level lifting requires the separate state/input/schedule and interface hypotheses.

6. **Evidence is read-only.** A numerical-budget receipt binds the endpoints, complete domain/coverage source, bias, output ports, graph, policy and budget. It is not a B1 BIT/ALG_AND_BIT authorization or a live commit path. The full algebra proofs, actual fixed-graph experiments and independently checked finite evidence remain distinct.
