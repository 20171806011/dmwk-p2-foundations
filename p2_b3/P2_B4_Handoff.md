# Coordinator handoff after P2-B3

This is a starting-point document, not B4 implementation or evidence. The current stage stops after B3 delivery and coordinator review. Adopt the original shared B4 specification before implementation; B3 does not replace it with a new research plan.

## Read and preserve

Read B3's Report, Definitions, Theorems, Numerical Analysis, Counterexamples, Evidence Map, Review, actual aggregate/independent/reproduction results, completion status and final integrity. Use previous P1/P2 evidence read-only. A passed small experiment, file inventory or stage label does not certify every assumption of a later-stage system.

## What the next stage may inherit

B3 supplies conditional bounds for fixed old/new endpoint banks. For nonnegative certified coefficients, a joint domain proof and initial error E0, the finite-time recurrence is E_t <= L_t E_(t-1)+beta_t, with the corresponding nonhomogeneous product-sum bound. Equal initial states are the E0=0 special case. The coefficients concern explicitly named maps, domains and numerical graphs; both executions' rounding contributions remain visible.

Uniform-in-time contraction statements require one valid invariant or another uniformly certified domain family, totality, uniformly bounded forcing and a common L<1 at every time. A finite tube proves only its stated horizon. ReLU's coordinatewise Lipschitz property does not protect a hard threshold branch, whose guard needs its own strict margin or a proof covering all branch combinations. A local output budget also does not imply BIT safety.

## Strict next-stage obligations

1. Continual patches change endpoint banks, potentially reachable activation spaces, Lipschitz constants, forcing, input envelopes and usable capacity. B3's fixed-bank coefficient cannot be silently reused after an update. Specify whether the comparison is between fixed programs, a patched execution and a reference execution, or two patch histories.
2. Retain A4's separation between algebraic parameter-space dimension, individual update rank, rank-capped families, storable endpoint sets, finite-graph BIT classes and A-target response capacity. Proved global space enlargement and sample rank estimates are different evidence. Nonzero response is not proof of useful learning.
3. For a changing system, certify joint reachability/domain inclusion across every admitted patch and state transition, or state a finite scope and reject when it expires. A new invariant, switching-system or joint-contraction theorem is an additional obligation, not an already delivered B3 result.
4. Actual Delta is W'-W after storage. Direct endpoint bounds already contain optimizer/projection/generation/storage effects. A named telescoping provenance decomposition is an alternative route, not additional copies of those same errors.
5. Maintain full version, endpoint, graph, nonlinear/branch convention, numerical policy, domain, initial relation, state and schedule binding. Transaction rejection must preserve weights, protected state and the specified optimizer snapshot. A read-only numerical receipt is not live BIT/ALG_AND_BIT authorization.
6. Preserve B1's actual failures: all 21 joint refusals passed their declared finite BIT diagnostic but failed ALG; dense FP32 AdamW accepted zero of eight attempts and retained loss 5/2. Do not relabel a positive conservative bound as observed D drift or retrospectively turn a refused attempt into learning progress.
7. Re-test only new or affected integration obligations with independent exact references. Keep complete finite domains, finite horizons, sampled trials, handwritten proofs and any future machine-checking evidence distinct. State cost and rejection reasons rather than conceal conservatism.

GPU, native BF16, general concurrency, arbitrary compiler/FMA/reassociation changes, universal learning performance and whole-host machine correctness remain unavailable to inherit. The current B3 delivery does not execute B4 or establish a long-term evolving-capacity theorem.
