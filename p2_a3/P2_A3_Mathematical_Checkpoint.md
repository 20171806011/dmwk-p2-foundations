# P2-A3 mathematical checkpoint before implementation

This checkpoint records the proved mathematical structure to be used when designing the A3 implementation. The final definitions and full proofs will be written in `P2_A3_Definitions.md` and `P2_A3_Theorems.md`. No finite test is used in this derivation.

1. Fix a scalar field K equal to Q or R, decoded stored endpoints W,W' in K^(k by d), fixed bias b, and the actual global activation set A for every protected use of one physical matrix in common input-column coordinates. Define Delta_eff=W'-W by exact subtraction of decoded endpoints, not a target-format subtraction instruction. For V=span_K(A) and any finite generator H of V, exact full-output equality on A is equivalent to Delta_eff A=0, equivalent to Delta_eff V=0, equivalent to Delta_eff H=0. Proof: subtract the same bias and extend the zero map through finite linear combinations; the converse uses A subset V. Empty A and rank-zero V are allowed.
2. If H generates a proved larger space U containing V, Delta_eff H=0 is sufficient for protection on A, but its converse fails in general. If H consists only of samples with no upper-inclusion proof, passing the generator condition establishes only that sampled span. Shared call-site spaces must be summed in the same physical frame.
3. If bias can also change, use augmented endpoints [W b], [W' b'] and actual augmented activations (h,1). This is an exact algebra identity; it does not reorder a floating bias-first instruction graph. Independent call-site biases need distinct augmented coordinates or separate obligations.
4. On a finite stored input a, define the actual fixed-graph output error relative to its exact affine expression. The executed old/new difference equals Delta_eff h+delta_b+e'-e. This yields pointwise norm bounds under explicit finite arithmetic hypotheses, not bitwise equivalence. Rounded programs are not linear maps in the input. A zero result at a real spanning basis cannot be extended by linearity to other stored inputs.
5. Program lifting requires a common inductive set I of complete protected configurations, a common legal input relation, total accepted execution, corresponding identical prepared call operands, raw local output/side-effect equality for all protected calls covered by I, deterministic unchanged control and numerical policy, and equal same-snapshot commits. An instruction-order induction yields equal successors and protected observations from equal configurations; a tick induction yields equal protected traces for every finite horizon.
6. A sequence of committed patches can be compared to the original program when each accepted endpoint pair is certified on the same complete domain I and fixed graph/policy, each transaction preserves protected configuration, and the original program preserves I. Equality of local maps is transitive across the finite prefix of weight versions. A certificate that covers only the current state cannot supply this step. Trusted serialized publication/version checks rule out replacing the checked old or new endpoint before commit; checksums alone are not semantic proofs.

For a k-by-d endpoint difference and true rank r, the exact annihilator has dimension k(d-r); at full rank its only element is zero. This is inherited linear algebra, not an A4 capacity investigation or a guarantee of storable bitwise-safe edits. A nonzero safe editable family must separately exhibit a changed legal A output. The concrete A3 reference will instantiate these sufficient conditions; it will not establish general P2-C composition.
