# Original-source checks and attribution limits

The request included incomplete citation labels. These were not treated as verified references. [reference_verification.json](reference_verification.json) records actual requests, successful source hashes, bounded excerpts and failed requests. No PyTorch experiment was run.

1. **LAPACK DGELSD, original routine documentation.** Retrieved from [Netlib](https://netlib.org/lapack/double/dgelsd.f). The RCOND argument description says singular values `S(i) <= RCOND*S(1)` are treated as zero when determining effective rank. This verifies the threshold-dependent effective-rank point for that least-squares driver. It does not mean our SVD call is DGELSD, or that a threshold proves exact algebraic rank.
2. **NumPy 2.3.5, original SVD implementation/docstring.** Retrieved from the [official version-tagged source](https://raw.githubusercontent.com/numpy/numpy/v2.3.5/numpy/linalg/_linalg.py). The docstring identifies the `_gesdd` LAPACK routine. Inspection of the installed implementation additionally establishes that the public `numpy.linalg.svd` path uses double computation for float32 input and then casts results back to float32. Therefore output dtype alone is insufficient evidence of a single-precision solver. This round records an explicit float32 generalized-ufunc signature where that private, version-bound interface is used; it does not certify the compiled library or promise that a private API remains stable across versions.
3. **PyTorch SVD documentation source.** Retrieved from the [official source repository](https://raw.githubusercontent.com/pytorch/pytorch/main/torch/linalg/__init__.py), restricting excerpts to the `svd` docstring. It states that singular vectors are not unique, that implementations may return different singular vectors, and explains paired sign changes in the real case. The fetched main-branch source is identified by its content hash and retrieval time, not asserted to be an immutable release. Exact projector invariance under a complete basis sign/orthogonal change is separately proved here; arbitrary numerical threshold choices do not inherit that invariance automatically.

The public NumPy and PyTorch rendered documentation URLs returned HTTP 403 in this environment; the original official source files above were successfully retrieved instead. The label `Debian Manpages +1` did not identify a precise document, and the bare `tuhh.de` domain did not identify a paper. No numerical theorem is attributed to those incomplete references. The T3 decomposition, local-error recurrence and conservative gamma bound are derived with explicit hypotheses in [Theorems](P2_A2_Theorems.md).

These sources support narrow background statements. They do not establish novelty, certify this implementation, or substitute for its recorded experiments and independent review.
