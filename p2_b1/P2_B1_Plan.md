## Mathematical and evidence boundaries

All exact rank claims retain A4's distinction between dimension, individual rank, rank-capped family, finite endpoint count and target-response capacity. Prescribed exact responses require `X alpha in V => R alpha=0`; only then is the minimum rank `rank(R)`. Shared matrices use the merged global domain, never an unsupported sample rank.

The exact projection is not a rounding certificate. A submitted endpoint is checked using decoded `W'-W`. ALG and BIT remain distinct selectable claims; full protected rank only exhausts ALG. A BIT edit may violate the algebraic rank bound. New optimization wrappers do not inherit certification for GPU/native BF16, general concurrency, arbitrary compiler optimization or process-failure atomicity. Software BF16, locally audited CPU FP32, handwritten proofs and finite tests are labeled separately. No universal learning benefit, full long-term B4 guarantee or completed C-series system is claimed.
