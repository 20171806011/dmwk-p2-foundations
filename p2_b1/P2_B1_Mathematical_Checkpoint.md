# P2-B1 mathematical checkpoint before implementation

This checkpoint precedes B1 implementation. It states the exact and executable obligations for the reference described in the saved plan; full definitions and proofs will follow. No prior-stage evidence is changed or rerun.

1. Fix a globally justified protected space V subset K^d, K=Q or R, and its symmetric idempotent complement projector P. On n-by-d candidates, Pi_alg(G)=GP is a linear, idempotent, self-adjoint orthogonal projection in the Frobenius inner product onto U(V)={Delta:Delta V=0}. The residual G(I-P) is orthogonal to U(V), so GP uniquely minimizes ||G-Delta||_F over that exact linear space. This does not project onto the finite BIT endpoint set or prove a rounded update safe.
2. For a full-column-rank nullspace basis N in K^(d by c), c=d-dim V, every exact-safe update is uniquely Delta=Z N^T with Z in K^(n by c), and rank(Delta)=rank(Z). Low-rank Z=A B^T gives Delta=A B^T N^T, rank at most min(k,n,c), and represents every exact-safe rank-at-most-k update with suitable factors. Rational bases need not be orthonormal; the Gram inverse remains necessary in the orthogonal-projector formula.
3. Exact SGD with a scalar step applied to a safe direction remains in U(V). A momentum linear combination remains safe when all terms with nonzero coefficients are safe and the same protected space/projector is used. For m_new=beta*m+(1-beta)*g_safe with beta nonzero, m_new is safe iff m is safe; beta=0 resets the old component. Changing P or retaining an old off-space moment needs revalidation/reprojection. A vector norm clip that multiplies the entire update by one scalar preserves U(V); elementwise clipping or coordinatewise preconditioning generally does not.
4. Concrete optimizer failures: on V=span(1,1,1), g=(2,-1,-1) is safe, but sign/unequal coordinate normalization and component clipping can give a row with nonzero sum. First-step bias-corrected Adam with zero state gives g/(|g|+epsilon); its row sum is 2/(2+epsilon)-2/(1+epsilon), nonzero for epsilon>=0. Decay contributes -eta*lambda*W and is safe only if that term annihilates V or a later full-increment projection removes it. Projecting the gradient alone does not project arbitrary accumulated state, adaptive scaling, clipping or decay.
5. Therefore the projected route constructs the entire final ideal increment D, including all optimizer transformations, and then uses DP as its algebraic restriction. Rounding the endpoint W'=RN(W+DP) still need not preserve that property; acceptance must check the actual decoded Delta_eff=W'-W and the selected complete-domain execution contract. ALG and BIT remain distinct claims, and all A4 target-response compatibility/rank limitations remain in force.
6. Pi_safe is a partial endpoint/transaction operation: from a fixed old weight/optimizer/state snapshot it either returns an endpoint plus staged optimizer state accompanied by valid supported evidence, or refuses. It is not claimed to be a nearest projection, total function, linear map, differentiable operator or optimizer convergence theorem. Candidate records bind old weights, optimizer state/configuration, version, domain/invariant, graph, policy and schedule. All computations and checks precede one immutable publication. Any failure leaves the entire snapshot unchanged, including moments and optimizer step count.
7. Structural live fixture: fixed shared 2-by-3 bank with first columns I_2 and only the third column editable. D uses the fixed first-two-column sparse arithmetic graph at both globally declared shared sites over all q,u in canonical bits. The Boolean same-snapshot feedback recurrence is fixed and closed. A at e_3 reads the two reserved entries. Pure total validation may inspect them, but the protected D arithmetic excludes them. Nonzero finite endpoint updates can change A outputs while preserving all D outputs/state; arbitrary finite interleavings inherit the A3 induction under the same initial state/inputs/trusted schedule.

The candidate optimizer may use separately specified host arithmetic; its numeric results are not the protected BF16/FP32 execution model. The all-finite-time statement depends on correct fixed graph/rounding/storage, full domain coverage and trusted serialized publication. GPU/native BF16/general concurrency/arbitrary compiler transformations, process-failure atomicity and full machine verification are not inherited.
