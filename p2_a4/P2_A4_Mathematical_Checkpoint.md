# P2-A4 mathematical checkpoint before implementation

This checkpoint is saved before the A4 implementations and experiments. Full statements and proofs will appear in the Definitions and Theorems documents. Earlier artifacts remain read-only.

1. Fix K=Q or R, an n-by-d physical shared matrix, a globally justified protected span V of rank r, and c=d-r. Exact updates annihilating V form Hom(K^d/V,K^n), hence have dimension nc. Every update has rank at most min(n,c). With Delta=G P_perp and rank(G)<=k, rank(Delta)<=min(k,n,c). For each q<=min(k,n,c), choose q complement basis vectors, send them to independent output vectors, and send all other basis vectors to zero. This yields rank q and can take G=Delta because Delta P_perp=Delta. These are abstract algebraic constructions, not storage/execution guarantees.
2. If protection increases from V to U containing V, the exact annihilator space decreases; its dimension loses n(dim U-dim V). Shared sites require the summed global space. A proved upper space gives conservative lower capacity, while an unproved sample space can only provide an optimistic upper bound on algebraic capacity. Full rank removes every nonzero exact annihilator. These implications do not classify finite floating observational equivalence.
3. For a finite target matrix X in K^(d by m), use the quotient map pi:K^d->K^d/V and Y=pi X in chosen quotient coordinates. Its rank is s=rank([H X])-r. The exact target-response image has dimension ns; its kernel inside the annihilator has dimension n(c-s). A prescribed response R is feasible iff ker(Y) is contained in ker(R), equivalently X alpha in V implies R alpha=0. Define a linear map on im(Y) by Y alpha -> R alpha, extend it by zero on a complement, and compose with pi. The constructed update has rank exactly rank(R), the minimum possible. Under generator rank cap k, add rank(R)<=k. A nonzero target response exists iff s>0, n>0 and k>=1 when capped; nonzero target-silent exact updates exist iff c>s.
4. Finite-format capacity is a set/count problem. Fix a stored old bank W, accepted canonical finite words, explicit endpoint masks/alphabets, graph, complete protected raw domain and all relevant effects. Let E be the allowed endpoint set, E_ALG={W' in E:(W'-W)V=0}, E_BIT={W' in E:all admitted fixed-graph protected raw observations agree}, and use their intersection when both are required. These are finite sets, generally not vector spaces. A3 supplies examples in each difference E_ALG minus E_BIT and E_BIT minus E_ALG, including full protected rank in the latter.
5. For the full canonical word alphabet of size N, |E_ALG|<=N^(nc): an nc-dimensional affine subspace has an injective projection onto nc coordinate positions, and each such stored coordinate has at most N choices. If W is admitted then at least the no-op belongs. Mask restrictions can reduce the affine dimension and count further. Every response-image count is at most its endpoint-set count and, for m accepted n-word target outputs, at most N^(nm). Counting restricted candidate alphabets does not count all BF16/FP32 banks.
6. A structural reserved-column set J is algebraically unconstrained exactly when every protected vector has zero coordinates in J. It supplies n|J| free coordinate entries, compared with geometric freedom nc, so the algebraic reservation cost is n(c-|J|). A fixed sparse D graph that never reads those mutable entries preserves its complete instruction trace under finite stored edits; a corresponding A graph can read them. Geometric constraints can leave c>0 yet no individual safe coordinate column. A small layout example will state the compiler/graph assumptions explicitly rather than claim a general compiler result.
7. All executable acceptance still uses actual stored endpoints, a complete trusted domain/invariant, fixed graph and numerical policy, current version and same-snapshot serialized publication. Capacity enumeration alone is not commit authorization. Same protected initial state/input/schedule and A3's closure/interface premises are required for an all-finite-time program consequence.

The finite count and response theorems assume fixed admissibility/totality and do not infer task benefit from a changed output. Native BF16, GPU, general concurrency, arbitrary compiler optimization and full proof-assistant verification remain outside this stage's evidence.
