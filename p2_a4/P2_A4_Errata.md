# A4 errata and scope clarifications

The necessary A1–A3 handoff, definitions, proofs and execution contracts were examined read-only. No prior-stage error requiring replacement of old evidence has been identified in this scoped dependency check. This is not a new audit or rerun of every previous result. Any correction discovered in A4 is made in this directory only.

The following distinctions are enforced in this stage:

1. The unrestricted annihilator is a vector space. A rank-capped subset is generally not a vector space, and finite stored/BIT endpoint sets are not assigned its vector-space dimension.
2. Target rank is measured after quotienting by the complete protected space. A rank inequality alone does not establish compatibility of a prescribed response with relations among the target columns.
3. Finite response-image cardinality bounds assume accepted finite A executions. Rejected or overflowing A evaluations must be recorded separately rather than silently counted as ordinary outputs.
4. BIT monotonicity requires nested actual protected domains with the graph, observed outputs and admissibility fixed. Nested real spans alone do not supply that relation.
5. The structural fixture validates all endpoint words, including reserved entries. Read exclusion applies to the protected arithmetic subgraph after pure, total validation of admitted banks; it is not equality of every Python memory access, instruction, timing or power observation.
6. A positive algebraic dimension need not provide any distinct exact-safe stored endpoint at a fixed old bank. Conversely, full protected rank does not prohibit every finite-domain BIT edit. These are different capacity questions, not contradictory rank theorems.

Independent review findings and any actual implementation corrections are recorded in `P2_A4_Review.md`. No finite check is promoted to universal machine verification.
