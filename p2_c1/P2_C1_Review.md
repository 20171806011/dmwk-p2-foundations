# P2-C1 independent review

## Preimplementation checkpoint

The saved Plan, mathematical checkpoint, compiler interface, transaction design and B4 handoff were read before independent implementation. The checkpoint is valid within its explicit closed language and trusted serial model. No predecessor verifier or optimizer history is rerun.

The gate block `[[1,1,-1],[-1,0,1]]` applied to `(a,b,1)` with Boolean arguments, ordered separate multiply/add and coordinate ReLU yields exact AND and NOT under the declared canonical-zero finite-word policy. Expression induction plus simultaneous old-state publication can therefore establish source correspondence. A further induction can cover every finite admitted tick history; finite tests do not prove that induction by themselves.

The always-containing D space has rank three. It must remain distinct from the span actually generated by a particular program over all Boolean states and inputs, and from that program's reachable-only span. A constant/wire source can generate no gate activation at all. Structural A-block dimension `m*c` differs from unrestricted full-output annihilator dimension `(2+m)*c` and from any family preserving only selected D observations.

For the declared A domain `{0,e_j}`, every finite canonical A endpoint is total and returns a column or zero exactly. The finite structural-universe cardinalities `65279^(m*c)` and `4278190079^(m*c)` are correct for BF16 and FP32 respectively. They do not count unrestricted all-matrix BIT classes. Exact initial A anchors are separate from later protected tasks and must be stored exactly; unsupported dense domains are not silently certified.

The artifact checker must reconstruct the complete graph from the externally expected source and budget. A generic check of the supplied local gates cannot discover an omitted external call. The live owner must retain detached source/artifact/configuration values and bind complete endpoint/state/optimizer/version/ledger identity. Accepted updates preserve the designated D observations, whereas rejection preserves the whole owned snapshot. Numerical or geometric read-only diagnostics cannot authorize publication.

## Independent method

The independent verifier owns its Boolean source interpreter, eager macro call-cost reference, ordered-word nearest-even search, exact word decoding, determinant/minor ranks and independent serial update expectations. Expected source values do not call the compiler's source interpreter or lowering. Actual compiled execution is compared against those references.

## Findings from the full proofs and implementation

T1–T3 establish source correspondence by induction on expressions, then on actual tick history under Boolean closure and old-state reads. The full-state step enumeration used by the compiler is valid for a nonempty proper initial subset precisely because its domain includes every Boolean state. Independent tests included a machine with one reachable state whose exact reachable gate-activation rank is one and whose all-state rank is two. Across the finite test families the reported envelope ranks span zero through three.

T4–T6 separate four different objects. The structural mask has exact dimension `mc`, the full-output annihilator of the three-coordinate envelope has dimension `(2+m)c`, admissible finite endpoints have cardinality `N_F^(mc)`, and equality of observations ranges over the specified D execution graph. The basis A input interface recovers every stored column including subnormal and maximum finite coefficients. On denser A inputs that totality argument would require new bounds. Parameter matrix storage alone excludes program graph, activation wires and state buffers. The per-tick operation receipt accounts for 12 separate binary arithmetic operations and two ReLUs per primitive D call.

The Frobenius projection theorem follows directly from the orthogonal coordinate masks on the input and output axes. The constant `AND(1,1)` source witnesses failure of a broader authorization rule. Its complete generated activation span is globally one dimensional. Replacing the first row by `(2^p,1,-2^p)` leaves its exact action equal to one on the generator, while the specified rounded graph yields zero. Conversely, changing the unused zero coefficient of the NOT row to the smallest subnormal leaves the Boolean gate outputs equal at all four Boolean operand combinations yet fails annihilation on the reserved ambient span. The exact gate refuses both edits. A previously recorded positive conservative error budget cannot authorize either.

T7 relies on reconstruction from the *externally expected* source, budget, initial anchors and policy. A self-consistent artifact can describe a different program. The pure execution API checks its embedded source; a caller establishes the intended program by using the expected-source checker or constructing the live owner. T8 also requires a trusted serial owner, the same initial D state, common inputs and schedule, complete immutable operation graph and ONE publication point. Prepare, optimizer evolution, candidate endpoint checks, ledger construction and all protocol rejections precede this assignment. T9 uses a fixed structural class and complete domain. Its capacity result coexists with an optimizer producing zero effective word changes.

## Actual independent run

The independent run passed 212,851 assertions with 95 expected refusals, zero unexpected failures and seed 20261114. The recorded primary wall time was 18.677387929 seconds. Four relevant source SHA256 bindings cover the independent verifier, compiler, C1 runtime and compiled-program owner. The underlying arithmetic library remains a preserved dependency. The word oracle decodes raw finite words to exact rationals and selects a nearest word by binary search and explicit tie parity. Every source output and successor is obtained by recursive Boolean interpretation independently of the compiler's lowering. The instruction-level oracle additionally interprets the emitted wire list and checks actual argument words, preactivations, coordinate ReLUs, output selectors and execution counts. Ranks are checked via determinants of minors. CHECKS includes repeated assertions within those loops. These counts, source digests and actual costs describe this particular host execution.

The proof review and independent checks identified no blocking inconsistency within the declared source, format, domain, and serial execution premises. General concurrency, crash safety, GPU, native BF16, arbitrary optimized graphs, machine verification of the host, and general learning performance remain open. A new source domain or externally produced graph requires its own correspondence and containment proof. Foreign-directory reproduction is recorded separately by the C1 reproduction driver.
