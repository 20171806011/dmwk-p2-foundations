# Coordinator handoff after P2-C1

This is a future-stage starting point, not C2 implementation. Stop after the scoped C1 delivery and coordinator review. Read the original C2 specification before choosing its precise combination/interface problem; C1 does not complete bidirectional composition, C3 coordinate migration or C4 arbitrary finite-precision execution.

## Required read-only evidence

Read C1 Plan, Definitions, Theorems, Compiler/interface/transaction specifications, Counterexamples, Report, Evidence Map, Review, actual primary/independent/reproduction records, completion and final integrity. Preserve C1 and every older stage/publication artifact. No stage-complete label grants blanket trust to a new source, graph, layout or backend.

## Strict starting point

1. The source is a closed finite Boolean synchronous state-machine IR. All state/output expressions read the same old state and common input; the trusted compiler lowers the entire source to a complete eager AND/NOT graph. The program is the graph plus shared bank, not the constant gate bank alone.
2. D prepares `(a,b,1,0_A)` at every generated site. The rank-three first-coordinate space is a proved global containing space under Boolean invariance. Complete all-state/input/site enumeration can report a tighter envelope; a smaller initial reachable set is a separate question. No observed sample rank supplies global authority.
3. The accepted layout fixes its two-row AND/NOT block, zero cross connections, input preparations, bias/activation policy, ports, state and schedule. Only the A block is writable. This whole interface is necessary; a displayed block-diagonal matrix alone is not a program isolation proof.
4. Structural algebraic dimension is `a_rows*a_cols`; full-output annihilator dimension for the reserved rank-three space is `(2+a_rows)*a_cols`. Per-update rank, generator family, finite stored class, A response and learning benefit remain different. Under the zero/basis A domain, all finite canonical A blocks are total and their complete basis signatures are injective. This restricted-domain theorem does not cover arbitrary dense A inputs.
5. Initial A anchor compatibility and exact representability are checked. Those anchors initialize learnable behavior; they are not immutable tasks during later updates. New protected task admission needs a new compatible-anchor/domain contract at the actual admission endpoint.
6. Actual stored increments include optimizer and quantization effects. The structural mask is a supported axis-aligned geometric projector; arbitrary geometric annihilation still does not imply rounded equality. New numerical comparisons need both execution roundings and new graph/domain/range evidence.
7. Compiler certificate checking reconstructs from the externally expected complete source, budgets and policy. A generic validator for a submitted list cannot discover omitted external calls or effects. Hash consistency is not source-intent authentication.
8. A new trusted serial owner binds source/graph/layout/domain, actual endpoints/versions, D state, optimizer, counters, schedule and ledgers. It stages all checks before one publication. Rejection preserves the full owner. Successful A updates may change metadata while preserving the specified D projection. Numerical evidence has no publication authority.

## What C2 must not silently assume

Any A-to-D feedback, shared input preparation, cross-region state access, changed effects, new branch, activation, normalization or optimizer-dependent schedule changes C1's premises. Specify the allowed interface, legitimate changes in D inputs versus unauthorized internal interference, source correspondence and complete domain coverage. C1's exact one-way structural fixture is not a proof of arbitrary bidirectional composition.

Do not transfer fixed-layout coefficients or masks to a new graph without proof. Do not equate a safe final total update with every-prefix safety, a per-step rank bound with cumulative rank, or BF16 stagnation with exhaustion of the fixed algebraic space. Keep B4's fixed/cumulative/moving-space distinctions and B1's negative evidence: 21 BIT-equal but ALG-failing refusals, plus dense FP32 AdamW zero accepted updates in eight attempts at unchanged loss 5/2.

General concurrency, crash consistency, hostile private memory, GPU/native BF16, arbitrary compiler/FMA/reassociation, full-host machine proof and universal learning benefits remain uncertified. OGD/GPM source checks are a bounded literature comparison, not proof of novelty or performance superiority.
